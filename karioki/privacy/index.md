# Glyphē apps

広告なし・アカウント不要の iPhone アプリ。

## Yoi to Ake

「最後はいつ？」がわかる、家事と用事の記録。ウィジェットのチェックで、アプリを開かずに記録できます。

**[App Store で見る](https://apps.apple.com/jp/app/yoi-to-ake/id6833862523)**

[サポート](https://glyphe-apps.github.io/yoi-to-ake/support/) / [プライバシーポリシー](https://glyphe-apps.github.io/yoi-to-ake/privacy/)

## Keyboardist

カーソルを自在に動かす、コピー履歴つきの日本語・英語キーボード。無料で使えます。

**[App Store で見る](https://apps.apple.com/jp/app/keyboardist/id6825295043)**

[サポート](https://glyphe-apps.github.io/keyboardist/support/) / [プライバシーポリシー](https://glyphe-apps.github.io/keyboardist/privacy/)

## Karioki

画面の文字をコピー。写真やスクリーンショットを、期限つきで一時保管。

**[App Store で見る](https://apps.apple.com/jp/app/karioki/id6825285499)**

[サポート](https://glyphe-apps.github.io/karioki/support/) / [プライバシーポリシー](https://glyphe-apps.github.io/karioki/privacy/)

## Time is Dots

時間の流れを、ドットで。ロック画面とダイナミックアイランドで、時間の経過が見えます。

**[App Store で見る](https://apps.apple.com/jp/app/time-is-dots/id6831161300)**

[サポート](https://glyphe-apps.github.io/time-is-dots/support/) / [プライバシーポリシー](https://glyphe-apps.github.io/time-is-dots/privacy/)
